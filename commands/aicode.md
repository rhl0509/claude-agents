ai-code-auditor 서브에이전트를 사용해 AI가 생성한 코드의 보안 기본값 결함을 점검해줘 — 클라이언트 도달 경로의 하드코딩 시크릿, 행 수준 보안(RLS) 미적용·블랭킷 정책·클라이언트 조작 가능 값으로 권한 판정, 요청 입력이 시스템 프롬프트·툴 호출에 도달하는 프롬프트 인젝션 싱크.

대상: $ARGUMENTS

경로가 비어 있으면 현재 git 변경분을 점검한다. 발견마다 CWE를 매핑하고, 공개 설계된 키(anon·publishable 등)는 오탐으로 울리지 않는다. 시크릿은 코드 제거뿐 아니라 프로바이더 회전 절차까지 제시하고, 원문 시크릿 값은 보고에 되찍지 않는다.
