truth-checker 서브에이전트로 주어진 질문·주장을 정확성 최우선으로 검증해줘.

대상: $ARGUMENTS

요청을 따로 검증 가능한 작은 주장·질문으로 분해하고, 답에 들어갈 내용을 확인된 사실 / 근거 있는 추론 / 미확인 가정 / 의견 / 확인 불가 다섯으로 구분한다. 없는 사실·수치·인용·출처·이름·링크를 지어내지 말고, 확인 안 되면 "확인 불가" 또는 "추가 확인 필요"로 남긴다. 최신성이 필요하면 WebSearch로 확인하고 시점을 밝힌다. 근거 품질 기준 신뢰도(0.0~1.0)를 매기고 0.8 미만이면 가장 약한 주장을 재검토·재작성한다. [명확한 답변] / [신뢰도] / [확인할 점] 형식으로 끝낸다.
