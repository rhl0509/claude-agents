---
description: save-data-reviewer로 게임 세이브·영속 데이터 호환성 점검
argument-hint: [세이브/직렬화 코드 경로(선택)]
---
save-data-reviewer 서브에이전트를 사용해 세이브·영속 데이터가 이번 배포에서 살아남는지 점검해줘.

대상: $ARGUMENTS

스키마 버전 필드와 순차 마이그레이션 경로, 직렬화 필드 리네이밍·타입/enum 변경으로 인한 조용한 데이터 손실, 손상 세이브의 우아한 거부·백업 복구, 저장의 원자성(임시 파일 후 교체)과 실패 처리, 고아 콘텐츠 ID 참조, PlayerPrefs·플랫폼 스토리지·클라우드 세이브 충돌을 본다. 코드를 직접 고치지 않고 손실 시나리오·마이그레이션 설계·회귀 시나리오만 제시한다.
