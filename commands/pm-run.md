Workflow 도구를 사용해 `pm-orchestrate` 워크플로를 실행하라. `name: "pm-orchestrate"`, `args`에는 아래 목표 문자열을 그대로 넘겨라.

목표: $ARGUMENTS

이 워크플로는 ① project-manager로 목표를 WBS로 분해·전문 에이전트에 라우팅하고 ② 라우팅된 전문 에이전트들을 실제로 실행(팬아웃)한 뒤 ③ 결과를 통합해 실행 순서·다음 착수·리스크로 보고한다. 전문 에이전트는 읽기 전용(리뷰·설계·분석)이라 코드 편집은 하지 않는다 — 통합 리포트를 받은 뒤의 코드 편집은 네(메인 세션)가 후속으로 진행한다.

계획만 필요하고 실행은 원치 않으면 대신 `/pm`(project-manager 서브에이전트)을 쓴다.
