slide-deck-reviewer 서브에이전트를 사용해 발표 슬라이드 덱이 구조 규약을 지키는지 점검해줘.

대상: $ARGUMENTS

규약 정본 `D:\presentation\INDEX.md`를 먼저 읽어 기준으로 삼는다. 슬라이드 파일과 뷰어 `slides` 배열·import·하드코딩 페이지 번호의 동기화(고아 슬라이드·번호 건너뜀 포함), `.slide` 최상위 누락과 1440×810을 벗어나는 좌표·스케일과 충돌하는 vh/%/미디어쿼리, 투사 가독성 최소 폰트(본문 14px·카드 제목 16px), 조작 UI의 `data-nav` 누락으로 인한 클릭 오작동과 시스템 alert 사용, 에셋 참조 대 실제 파일 전수 대조와 디렉터리 혼동·비ASCII 파일명, 템플릿 복사 후 안 바꾼 프로젝트 고유값(name·포트·metadata·PPTX 파일명·로고·이전 팀 표기), `turbopack: {}` 누락과 동적 import 패키지의 의존성 미선언을 본다.

**틀만 보고 내용은 보지 않는다** — 수치의 사실성·정합, 발표 대본과 슬라이드 내용 일치, 챕터 구성·목차 타당성, 문구 설득력은 프로젝트마다 달라 판정하지 않는다(각각 fact-checker·작성자 판단·proposal-strategist/curriculum-designer·copy-reviewer).

심각도는 발표 중 관객에게 보이는 결과 기준으로 매기고, 정적으로 판정 불가한 것은 "확인 필요"와 확인 방법으로 분리한다. 코드·에셋을 직접 고치지 않고 점검·수정 방향만 제시한다.
