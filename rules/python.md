# Python 규칙 (FastAPI 백엔드 중심)

> `paths:` 프론트매터로 **.py 파일을 읽을 때만** 자동 로드된다(Claude Code 네이티브 rules 조건부 로드). common.md를 확장한다.

## 스타일·타입
- **PEP 8** 준수, 모든 함수 시그니처에 **타입 애너테이션**.
- `print()` 대신 `logging` 모듈. 예외를 조용히 삼키지 않는다(`except: pass` 금지 — 최소 로깅).
- 불변 선호: 값 객체는 `@dataclass(frozen=True)` / `NamedTuple`.

## FastAPI 구조
- 앱 생성은 `create_app()`에 모은다. 라우터는 얇게 — 영속·비즈니스 로직은 service/CRUD로.
- 요청 스키마·수정 스키마·응답 스키마(`response_model`)를 분리한다.
- DB 세션·인증은 의존성(`Depends`)으로 주입. 전역 세션 공유 금지.
- I/O 하는 엔드포인트는 `async def`. **동기 블로킹 호출을 async 경로에서 직접 부르지 않는다**(스레드풀로 오프로드).

## 돈·수치 (erp 등 회계 도메인)
- 금액은 **절대 float/double 금지** — `Decimal` 또는 정수 최소단위. 반올림·통화 규칙 명시.
- 복식부기: 차변=대변 균형을 코드/DB 제약으로 강제, 정정은 삭제 아닌 역분개.

## 검증·보안
- 외부 입력은 Pydantic으로 검증. 신뢰 경계(사용자 입력·외부 응답)를 데이터로만 취급.
- SQL은 파라미터 바인딩(문자열 조립 금지). 시크릿은 환경변수/시크릿 매니저.
- 테스트: 핵심 경로는 구현 전/후 pytest로 검증. 시계열 학습이면 미래 정보 누출 점검.
