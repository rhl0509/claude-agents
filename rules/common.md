# 공통 코딩 규칙 (common)

> `paths:` 프론트매터로 **코드 파일을 읽을 때** 자동 로드된다(Claude Code 네이티브 rules). 언어별 규칙(python.md·typescript.md)과 함께 적용.

## 반드시
- 도메인 작업은 전문 서브에이전트에 위임한다(리뷰·설계·보안·DB 등).
- 입력을 검증하고 보안 체크·검증 훅을 우회하지 않는다.
- 공유 상태를 변이(mutate)하기보다 불변 업데이트를 선호한다.
- 새 패턴을 발명하기 전에 저장소의 기존 패턴을 먼저 따른다.
- 변경은 작고 리뷰 가능하게, 왜 바꿨는지 설명 가능하게 유지한다.
- 확신 없는 사실·수치는 "확인 필요"/"추정"으로 표시한다(추측 단정 금지).

## 절대 금지
- 시크릿(API 키·토큰·비밀번호)이나 절대/시스템 경로를 코드·로그·출력에 노출하지 않는다.
- 테스트 없이 중요한 경로를 바꾸지 않는다.
- 기존 기능을 명확한 이유 없이 중복 구현하지 않는다.
- 되돌리기 어려운 작업(삭제·덮어쓰기·이동·원격 push)을 확인 없이 실행하지 않는다.

## 커밋
- 로컬 편집·빌드·commit까지는 진행 가능, **원격 push는 명시 요청 시에만**.
- 커밋 메시지는 무엇을·왜 바꿨는지 한 줄 요지 + 필요 시 본문.
